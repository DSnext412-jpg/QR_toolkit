# 📖 About

**QR Code Toolkit** is a feature-rich Python CLI application that allows you to generate and scan QR codes with ease.

Whether you want to share a website, connect to Wi-Fi instantly, or create branded QR codes with your logo, this toolkit has you covered.

Perfect for beginners learning Python as well as developers looking for a practical automation project.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/QR_Code_Toolkit.git
```

```bash
cd QR_Code_Toolkit
```

### Install Requirements

```bash
pip install -r requirements.txt
```
